HK NEWS PC STUDIO PRO — कंप्यूटर / लैपटॉप पर चलाने का तरीका
==================================================================

तरीका 1 (सबसे आसान — बिना किसी इंस्टॉलेशन के तुरंत चलाएँ):
1. मोबाइल ऐप के "PC ऐप" टैब से HK_NEWS_PC_Studio.html को डाउनलोड या WhatsApp/Email से अपने कंप्यूटर (Windows / Mac / Linux) पर भेजें।
2. कंप्यूटर में HK_NEWS_PC_Studio.html पर डबल-क्लिक करें (या Windows पर Start_HK_NEWS_PC.bat चलाएँ)।
3. यह तुरंत Chrome या Microsoft Edge में खुल जाएगा। ऊपर दाईं ओर "Install App" (+) आइकन पर क्लिक करके इसे असली Windows सॉफ्टवेयर आइकन की तरह Desktop पर पिन कर लें!

तरीका 2 (Electron Desktop EXE बनाने के लिए):
1. कंप्यूटर में Node.js इंस्टॉल करें।
2. pc-software फ़ोल्डर में कमांड चलाएँ:
   npm install
   npm start       (सीधे डेस्कटॉप ऐप चलाने के लिए)
   npm run build-win  (Windows .exe इंस्टॉलर बनाने के लिए)
